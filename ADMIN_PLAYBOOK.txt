1. APPROVE A NEW USER
---------------------
When a user registers on the site, they land on "Access Pending."
Run this to grant cockpit access:

  UPDATE public.user_access
  SET approved = true, approved_at = now()
  WHERE email = 'user@example.com';


2. REVOKE ACCESS (keep account)
-------------------------------
User can still log in but sees "Access Pending" again:

  UPDATE public.user_access
  SET approved = false, approved_at = null
  WHERE email = 'user@example.com';


3. DELETE A USER COMPLETELY
---------------------------
Removes both the access record and the auth account:

  DELETE FROM public.user_access
  WHERE email = 'user@example.com';

  DELETE FROM auth.users
  WHERE email = 'user@example.com';


4. LIST ALL USERS AND STATUS
-----------------------------

  SELECT email, approved, approved_at, created_at
  FROM public.user_access
  ORDER BY created_at DESC;


5. PRE-APPROVE A USER (before they register)
---------------------------------------------
Insert a pre-approved row so they get instant access on signup:

  INSERT INTO public.user_access (email, approved, approved_at)
  VALUES ('user@example.com', true, now());


6. COUNT ACTIVE VS PENDING
---------------------------

  SELECT
    COUNT(*) FILTER (WHERE approved = true) AS active,
    COUNT(*) FILTER (WHERE approved = false) AS pending,
    COUNT(*) AS total
  FROM public.user_access;
